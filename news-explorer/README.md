# News Explorer

A news app where you can find the latest news and add articles to your profile.

## Description

The app uses the News API to find relevant articles over the last week based on the search prompt. It will display articles in a row of 3, and users can save articles, which will be displayed on a separate page, but only if they are logged in. Registering does not automatically log you in, you must log in manually. The saved page will display how many articles the user has saved, as well as how many different keywords for the articles. The keywords used when searching for the article saves to the article in the saved page. The save icon is disabled for users that are not logged in. There is also a delete button on the saved page for users to delete articles that they no longer wish to have saved. There is no backend and it currently saves user data and a token in localStorage.
